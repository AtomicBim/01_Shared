Модель из Revit необходимо экспортировать в Tangl с высокой детализацией.
Справочник состоит из двух уровней - <u>ВДЦ_15_1ур_Вентиляция<u> и</u> ВДЦ_15_2ур_Вентиляция.</u>

В привязке справочника **<u>первого уровня</u>** идет отбор элементов по параметрам:
-**Category** с неглубоким поиском (со значением = Оборудование/Арматура воздуховодов/Воздухораспределители/Соединительные детали воздуховодов/Воздуховоды/Гибкие воздуховоды/Материалы изоляции воздуховодов/Материалы внутренней изоляции воздуховодов).
-**Группа модели** с неглубоким поиском, параметр типа (со значением = Оборудование вентиляционное/Арматура воздуховодов/Воздухораспределители/Соединительные детали воздуховодов/Воздуховоды/Материалы изоляции воздуховодов).
-**\_Группа спецификации** с глубоким поиском (со значением начинающимся на 1). Глубокий поиск сделан для поиска параметров в типе или экземпляре, поскольку семейства настроены по-разному и у каких-то параметр в типе, каких-то в экземпляре.

Объемы работ на первом уровне не собираются. Параметры объема **\_Положение**, **\_Тип системы**, **\_Этаж**, **\_Группа спецификации** добавлены для создания параметрических позиций, которые позволяют группировать параметры в соответствии со спецификацией [[Как устроена спецификация ОВ - Вентиляция.]]

На первом уровне 4 параметрические позиции, которые сгруппированы для создания очередности элементов как в спецификации Revit.
-Первая позиция определяется по параметру **\_Положение** (Localisation). Идет деление на группы - Основная часть, Соседский центр, Выставочный салон, Фитнес. Выполняется с помощью оператора ЕСЛИ и проверки на существование (isnullorempty()) параметров, содержание (contains()) в параметрах определенных выражений: *if( isnullorempty( Localisation ) , "Основная часть" , if( contains( "соседский центр" , lower( Localisation ) ) , "Соседский центр" , if( contains( "выставочный" , lower( Localisation ) ) , "Выставочный салон" ,  if( contains( "офис" , lower( Localisation ) ) , "Офис" ,  if( contains( "фитнес" , lower( Localisation ) ) , "Фитнес" , "Основная часть" ) ) ) ) )*.
-Вторая позиция определяется также по параметру **\_Положение** (Localisation). Выводит сам параметр, в котором записано к каким помещениям относится элемент системы.
-Третья позиция определяется по параметру **\_Тип системы** (System Type). Идет деление элементов по типам систем в результате анализа.
-Четвертая позиция группирует элементы по параметру **\_Группа спецификации**.

Справочник <u>**второго уровня**</u> содержит позиции в соответствии со спецификацией Revit и таблицей идентификации:
"P:\03_БИБЛИОТЕКА\Revit_1_Данные\Идентификация элементов\АСК_Идентификация элементов_ОВ_v1.0 (в работе).xlsx"

Для позиций с единицами измерения в штуках для определения объемов работ записано Формула=1. Для определения объема позиций в м2 нужно получить параметр **\_Площадь** (Area) - Формула=Area. Для всех позиций требуются параметры **\_Техническая характеристика** (Description), **_Наименование** (Name)**, \_Группа спецификации** (SpecificationGroup), **Изготовитель** (Manufacturer), **\_Положение** (Localisation) и **\_Тип системы** (SystemType).

Параметрические позиции создаются:
1. На основе параметра **\_Группа спецификации** (SpecificationGroup).
2. Путем совмещения параметров **\_Техническая характеристика** (Description),  **_Наименование** (Name) и **Изготовитель** (Manufacturer):
concatenate( Description ,if( isnullorempty( Name ) , "" ,concatenate( "_" ,Name ) ) ,if( isnullorempty( Manufacturer ) , "" ,  concatenate( "_Изготовитель: " ,Manufacturer ) ) ).
Объединение сделано для разделения элементов на две позиции в том случае, когда два элемента имеют одинаковый параметр **\_Техническая характеристика**, но разные при этом **_Наименование** (Name) или **Изготовитель** (Manufacturer).
