Справочник состоит из двух уровней - <u>ВДЦ_15_1ур_Вентиляция<u> и</u> ВДЦ_15_2ур_Вентиляция.</u>
- В привязке справочника первого уровня идет отбор элементов по параметрам:
-**Category** с неглубоким поиском (со значением равным Оборудование/Арматура воздуховодов/Воздухораспределители/Соединительные детали воздуховодов/Воздуховоды/Гибкие воздуховоды/Материалы изоляции воздуховодов/Материалы внутренней изоляции воздуховодов),
-**\_Группа спецификации** с глубоким поиском (со значением начинающимся на 1). Глубокий поиск сделан для поиска параметров в типе или экземпляре, поскольку семейства настроены по-разному и у каких-то параметр в типе, каких-то в экземпляре.
-**Группа модели** с неглубоким поиском (со значением равным Оборудование вентиляционное/Арматура воздуховодов/Воздухораспределители/Соединительные детали воздуховодов/Воздуховоды/Материалы изоляции воздуховодов).
- Объемы работ на первом уровне не собираются. Параметры объема \_Положение, \_Тип системы, \_Группа спецификации добавлены для создания параметрических позиций, которые позволяют группировать параметры в соответствии со спецификацией [[Как устроена спецификация ОВ]]
- На первом уровне 4 параметрические позиции, которые сгруппированы для создания очередности позиций как в спецификации Revit
-Первая позиция определяется по параметру \_Положение (Localisation). Идет деление на группы - Основная часть, Соседский центр, Выставочный салон, Фитнес.
