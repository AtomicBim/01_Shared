# Краткий гайд по работе с Git-репозиторием Obsidian

## Первоначальная настройка на новом компьютере

```bash
# Клонирование репозитория
git clone https://github.com/AtomicBim/AtomObsidian.git

# Перейти в папку проекта
cd AtomObsidian
```

## Ежедневные операции

### Получение изменений

```bash
# Проверить наличие изменений на сервере и скачать их
git pull
```

### Проверка статуса файлов

```bash
# Проверить статус файлов (изменённые, новые, удалённые)
git status
```

### Добавление новых файлов

```bash
# Добавить все новое
git add 00_Data/01_Shared/
```

### Создание коммита

```bash
# Создать коммит с описанием сделанных изменений
git commit -m "Добавлены заметки по теме X"
```

### Отправка изменений на сервер

```bash
# Отправить все закоммиченные изменения на GitHub
git push
```

## Полезные дополнительные команды

```bash
# Просмотр истории коммитов
git log --oneline

# Просмотр изменений в файле
git diff путь/к/файлу.md

# Отмена изменений в файле до коммита
git checkout -- путь/к/файлу.md

# Создание новой ветки для экспериментов
git checkout -b имя_новой_ветки
```

## Напоминание

Помните, что согласно настройке `.gitignore`, Git отслеживает только:
- Файл `.gitignore`
- Содержимое папки `00_Data/01_Shared/`

Все остальные файлы игнорируются и не будут синхронизированы между компьютерами.
