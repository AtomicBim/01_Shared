# 01_Shared - Общая папка для рабочих заметок Obsidian

## Обзор проекта

Этот репозиторий представляет собой общую папку для хранения и синхронизации рабочих заметок, используемых в Obsidian. Папка предназначена для совместного использования между различными компьютерами и участниками команды, обеспечивая централизованное хранение документации и методических материалов.

## Назначение

Основная цель данной папки - предоставить общее хранилище для:

- Методических рекомендаций по работе с BIM-моделями
- Инструкций по проверке проектной документации
- Рабочих процессов и стандартов проектирования
- Обучающих материалов и справочников
- Документации по использованию различных программных продуктов (Revit, Tangl и др.)

## Структура папки

В папке содержатся следующие типы документов:

- **Алгоритмические проверки**: Инструкции по автоматизированной проверке моделей в Revit
- **Техническая документация**: Описания спецификаций и процессов выгрузки данных
- **Инструкции по работе**: Руководства по использованию различных инструментов
- **Справочники**: Документация по системам и процессам (например, вентиляция, армирование и др.)
- **Рабочие инструкции**: Описания этапов подготовки моделей и проверок

## Использование

Папка синхронизируется с помощью Git, что позволяет:

- Использовать обновленные методические материалы на разных компьютерах
- Отслеживать изменения в рабочих процессах
- Обмениваться информацией между участниками команды
- Поддерживать актуальность документации

## Технологии

- **Платформа хранения**: Obsidian (система управления заметками)
- **Система контроля версий**: Git
- **Формат хранения**: Markdown файлы
- **Интеграция**: Работа с BIM-платформами (Revit, Tangl и др.)

## Области применения

Документация в этой папке используется для:

- Проверки моделей в Revit на соответствие ТУ
- Подготовки моделей к выгрузке объемов
- Работы с армированием конструкций
- Спецификации систем (например, вентиляции)
- Обучения новых сотрудников

## Особенности

- Документация хранится в формате Markdown
- Используется для внутренних рабочих процессов
- Содержит методические материалы по разным аспектам проектирования
- Постоянно пополняется и обновляется
