## **Подготовка в Revit:**
### Обычная выгрузка АР:
1. Проверить идентификацию элементов по контрольным спецификациям.
2. Заполнить параметр \_Положение у наружных стен(Кровля, Цоколь, Перегородка, Нет).
3. Заполнить плагином параметр \_Этаж и проверить его.
4. Проверить материалы по контрольным спецификациям.
### Обычная выгрузка КР/КЖ:
1. Проверить идентификацию элементов по контрольным спецификациям.
2. Заполнить плагином параметр \_Этаж и проверить его.
3. Проверить правильность принадлежности к этажам перекрытий(перекрытие перекрывает этаж сверху).
4. Проверить материалы по контрольным спецификациям.

### Выгрузка для бюджета в 1С(модель АР):
1. Проверить идентификацию всех элементов по контрольным спецификациям.
2. Проверить материалы по контрольным спецификациям.
3. Добавить параметры в модель \_Радиальная стена, \_Тип расшивки для категории Стены.
4. Запустить плагин заполнения параметров \_Радиальная стена, \_Тип расшивки для стен с подгруженной связью КР/КЖ. Проверить правильность заполнения вручную.
5. Добавить категории для параметров \_Назначение, \_Имя помещения если требует плагин.
6. Запустить все плагины для заполнения параметров \_Назначение, \_Имя помещения с подгруженной связью КР/КЖ(для кладки, обшивок, каркасных перегородок, окон, дверей, отделки).
7.  Собрать спецификацию по нескольким категориям для быстрой проверки параметров \_Назначение, \_Имя помещения у всех элементов(или скопировать из другого проекта).
8. Дозаполнить \_Назначение, \_Имя помещения если не заполнилось автоматически.
9. Запустить остальные плагины - для заполнение параметра Огнестойкость у витражей, пустые строки.
10. Запустить плагин \_Этаж и проверить как привязались к этажам элементы.

### Выгрузка для бюджета в 1С(модель КР/КЖ):
1. Проверить идентификацию всех элементов по контрольным спецификациям.
2. Добавить параметры для категории Перекрытия \_Толщина, \_Смещение от уровня, если в модели присутствуют перекрытия выполненные моделью в контексте. Заполнить эти параметры вручную.
3. Запустить плагин \_Этаж и проверить как привязались к этажам элементы. Важно чтобы было четкое деление на выше/ниже 0.000.
4. Проверить материалы по контрольным спецификациям.
## Проверка в Tangl:
Проверить всё на нулевые позиции.
<u>"Двери, ворота металлические"</u> - проверить:
- наименования конечных позиций,
- привязку к обоим уровням,
- правильность назначенной позиции по первому уровню(МОП, Квартиры, Встройка и т.д.).
<u>"Внутренние отделочные работы"</u> - проверить:
- наличие отделки по всем помещениям,
- привязку к обоим уровням справочника,
- проверить всем ли слоям материалов назначены позиции справочника,
- проверить всем ли деревянным дверям назначена позиция установки дверных блоков,
- проверить контрольную сумму площадей с общей суммой по обшивкам и каркасным перегородкам.
<u>"Наружные отделочные работы (фасад)"</u> - проверить:
- отделка балконов/лоджий отдельно от остальной отделки.
"<u>Витражи, алюминиевые конструкции, остекление"</u> - проверить:
- привязку всех импостов и панелей к позициям,
- положение витражей в соответствии с позициями-балконный, холодный, теплый.
"<u>Архитектурные решения</u>" - проверить:
- привязку к обоим уровням,
- наименования конечных позиций и соответствие их названию позиции,
- соответствие положения стен в модели справочнику - облицовка, наружные, внутренние стены, ограждения и т.д.,
- все стены в м3, все перегородки в м2,
<u>"Подземная часть и фундаменты"</u> и <u>"Надземная часть - каркас"</u> - проверить:
- деление на выше/ниже 0.000, что плита над минусовым этажом относится к ниже нуля,
- совпадение суммы объемов стен и проверочного объема,
- проверить, что к позициям привязался материал,
